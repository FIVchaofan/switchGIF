在 1.1.0 基础上新增：

- **保存到手机**：结果页和单个作品预览页新增按钮，主动点击后才复制一份到系统相册 `Pictures/原速GIF`。
- **导入 GIF**：作品库支持从系统文件选择器导入 GIF，复制到应用内部；删除相册原文件不影响导入的副本。
- **变速**：默认 1.0× 原速，可选 0.5× / 0.75× / 1.0× / 1.5× / 2.0×；使用 FFmpeg `setpts` 改变时间戳，结果页显示实际时长和预期时长。
- 结果页显示当前倍速，文件名带倍速后缀（如 `_2.0x.gif`）。

隐私行为不变：未点「保存到手机」时，作品只存在应用内部，相册不可见；分享仍然只临时授权单张 GIF。
