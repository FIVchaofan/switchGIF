每个版本目录里都有：

- `version.json`：版本号、文件大小、SHA-256、构建日期。
- `SHA256.txt`：可用于校验文件。
- `RELEASE_NOTES.md`：版本说明。

所有版本使用同一张签名证书（SHA-256：`564307e0af3c426dbf00d2b57470f98fdfe0d017c8b53aa7b14ed150bdce5c52`），所以签名层面可以互相覆盖安装；系统仍可能因 `versionCode` 降低而阻止降级。

## 回退方法

1. 在表格里找到要回退的版本，下载对应 APK。
2. **优先尝试直接覆盖安装**（APK 使用同一签名密钥）。
3. 如果系统提示“版本降级”而拒绝安装，可以：
   - 用 ADB：`adb install -r -d YuansuGIF-v1.0.0.apk`（`-d` 允许降级）。
   - 或先卸载当前版本再安装——**注意：卸载会删除应用内部作品库里的所有 GIF**。
4. 回退前，请先把需要保留的 GIF 通过作品库的「分享」或 v1.2 的「保存到手机」发出去，或自行备份。

## 注意

- v1.0.0 会把 GIF 保存到系统相册；v1.1.0 默认保存在应用内部；v1.2.0 起默认也在内部，只有主动点「保存到手机」才写相册。
- v1.3.0 起作品库还支持图片/视频；默认同样不写相册，分享时按原格式发送。
- v1.3.2 起选择视频、导入图片/GIF/视频统一使用系统照片选择器，并按格式筛选。
- 所有版本使用同一个签名密钥（`android/keystore/yuansu-gif.jks`），不要丢失，否则后续版本无法覆盖升级。
- 版本号只增不减；新版本构建完成后会自动归档到新的版本目录。
